# Agent Instructions

## Project

This repository contains the VLM Explainability for Chest X-rays pilot.

The project evaluates whether a pretrained medical VLM uses stable, clinically grounded, and faithful visual evidence when answering semantically equivalent questions about frontal chest X-rays.
